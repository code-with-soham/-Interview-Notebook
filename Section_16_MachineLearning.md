## 16.2 Bias, Variance & Overfitting

### ✅ Important Topics
- [ ] Bias-Variance Tradeoff
- [ ] Overfitting vs Underfitting
- [ ] Regularization (L1 Lasso, L2 Ridge)
- [ ] Dropout (in Neural Networks)
- [ ] Early Stopping

### 📋 Interview Questions
1. Explain the Bias-Variance Tradeoff.
2. What does High Bias mean? (Underfitting). What does High Variance mean? (Overfitting).
3. How do you detect if your model is overfitting? (Training error is very low, but validation/test error is high).
4. What are some effective ways to prevent or reduce overfitting? (More data, Cross-validation, Regularization, reducing model complexity).
5. What is Regularization? Explain the difference between L1 (Lasso) and L2 (Ridge) Regularization.
6. Which type of regularization (L1 or L2) is useful for feature selection (making coefficients exactly zero)? (L1 / Lasso).

## 16.4 Model Evaluation & Validation

### ✅ Important Topics
- [ ] Cross-Validation (K-Fold)
- [ ] Confusion Matrix (TP, TN, FP, FN)
- [ ] Evaluation Metrics (Accuracy, Precision, Recall, F1-Score)
- [ ] ROC Curve and AUC
- [ ] MSE, RMSE, MAE (for Regression)

### 📋 Interview Questions
1. What is Cross-Validation? Explain K-Fold Cross-Validation. Why is it better than a simple train/test split?
2. Explain the components of a Confusion Matrix (True Positives, True Negatives, False Positives, False Negatives).
3. Define Accuracy. When is Accuracy a misleading metric? (Imbalanced datasets).
4. What is Precision? What is Recall? Explain the tradeoff between them.
5. You are building an ML model to detect cancer. Which is more important to maximize: Precision or Recall? Why? (Recall, to minimize False Negatives).
6. What is the F1-Score?
7. What is an ROC Curve? What does the AUC (Area Under the Curve) represent?
8. Name the common evaluation metrics used for Regression tasks. (Mean Squared Error, Root Mean Squared Error, Mean Absolute Error, R-Squared).
